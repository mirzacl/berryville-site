# berryville.app

The website for **BerryVille**, a cosy berry restaurant game for iPhone: the landing page, the privacy policy (`/privacy/`) and the support page (`/support/`). Plain HTML and CSS, no build step, served by GitHub Pages on the custom domain in `CNAME`.

- `index.html`: the landing page.
- `privacy/index.html`, `support/index.html`: the pages the App Store listing and the game's Settings link to (the game's `BerryLinks` points at them).
- `assets/`: the pixel art (rendered from the game's `Documentation/Brand/make_brand.py`), screenshots from the game's capture tests, and the game's Jersey 10 font (SIL Open Font License, `assets/fonts/Jersey10-OFL.txt`).
- Later, `app-ads.txt` goes at the root when rewarded videos go live.
